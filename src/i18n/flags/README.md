# Language flags

Local 4:3 SVGs from flag-icons 7.3.2 (MIT): https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3

Only the 11 supported language flags are bundled. EN uses gb, JA uses jp, KO uses kr, VI uses vn. The build embeds data URLs; no runtime downloads or LIKO dependency. Keep LICENSE when updating.
