# QiAct v1.4.7 发布说明

> 发布日期：2026-08-27 · 类型：新功能

## 新增：禁用动作管理

- 设置页新增「启用禁用动作设置」。
- 启用后，标题按钮列显示禁止入口；开启入口后显示「禁止」分页与底部「禁用」收录按钮。
- 选择人物与部位并开启收录模式后，点击动作即可加入禁止清单。
- 管理清单显示「部位、动作名称、对自己、对他人、删除」五个栏位。
- 「对自己」控制别人能否对玩家执行动作；「对他人」控制玩家能否对别人执行动作。
- 新收录的动作默认同时禁止两个方向，之后可分别调整。

## BC 原生偏好整合

- 禁止状态通过 BC 原生 `PreferenceSetActivityFactor` 写入 `Player.ArousalSettings`，并同步至账号服务器。
- 启用禁止前会保存该方向原本的偏好值；解除禁止或删除清单项目时恢复原值。
- 清单与插件设置同时保存于本机及账号扩展设置。

## 禁用互动总开关

- 禁止分页顶部新增「禁用互动」总开关，默认开启。
- 关闭时保留清单及每个方向的开关状态，但立即恢复原本 BC 偏好，不过滤任何动作。
- 重新开启后，依照保留的清单重新套用动作禁止设置。

## 介面调整

- 刷新按钮排列在标题栏右侧按钮列最前方、禁止按钮之前。
- 禁止清单改为完整面板宽度，并完善标题列、动作列与按钮外框。
- 所有支持语言均补齐新功能所需翻译键。

## 升级提示

- 油猴用户刷新 Bondage Club 页面即可自动更新。
- 通过 liko 插件管理器加载的用户会在下次刷新时取得新版。
